# Carpathian Trails

Навчальний проєкт із курсу «WEB-Технології та WEB-Дизайн» — адаптивний лендінг туроператора, що пропонує походи Українськими Карпатами.

## Про проєкт
Сайт розповідає про вершини Чорногори (Говерла, Туркул, Шпиці, Кукул), гірські озера й полонини (Несамовите, Бребенескул, Драгобрат, Пожижевська) та культуру Гуцульщини. Відвідувач може залишити заявку на тур через форму.

Повний опис ідеї, аудиторії, секцій і референсів — у файлі [CONCEPT.md](CONCEPT.md).

## Технології
- HTML5 (семантична розмітка)
- CSS3: custom properties, Flexbox, Grid
- Адаптивна верстка (mobile-first), світла й темна тема
