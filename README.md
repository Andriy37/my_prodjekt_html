# 🏔️ Carpathian Trails — Веб-застосунок про туризм у Карпатах

Підсумковий проєкт з курсу веб-розробки. Веб-сайт присвячений гірському туризму, красивим локаціям та культурі Гуцульщини.

🔗 **Жива демо-версія:** [Переглянути проєкт на GitHub Pages](https://<твій-username>.github.io/<назва-репозиторію>/)

---

## 🛠️ Використані технології
* **Frontend:** HTML5, CSS3, JavaScript (ES6+), Tailwind CSS (CDN)
* **React:** React 18, JSX, `useState`, CDN-підключення (`react-app.html`)
* **Backend:** Node.js, Express.js (папка `/server`)
* **Оптимізація та SEO:** Lighthouse, WebP, `loading="lazy"`, Open Graph, ARIA-атрибути
* **Деплой:** GitHub Pages

---

## 📂 Структура репозиторію
* `index.html` — Головна сторінка проєкту (HTML/CSS/JS + Tailwind)
* `react-app.html` — Інтерактивна React-версія з компонентами та `useState`
* `style.css` — Основні стилі та теми оформлення
* `script.js` — Логіка DOM, перемикач теми, бургер-меню та Fetch API
* `/server` — Express.js API-сервер для обробки GET/POST запитів
* `AI-NOTES.md` — Звіт про роботу з AI-асистентами (Пр. № 21)
* `PERFORMANCE.md` — Звіт з оптимізації продуктивності Lighthouse (Пр. № 23)
* `SEO-A11Y.md` — Звіт з SEO та доступності (Пр. № 24)
