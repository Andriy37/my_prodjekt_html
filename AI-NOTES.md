# Звіт з використання AI-асистента (Практичне заняття № 21)

## 1. Обраний інструмент
* **AI-асистент:** ChatGPT / Gemini

## 2. Промпти, які спрацювали ефективно
1. **Промпт для валідації:** «Додай у JS-обробник форми перевірку поля email та відображення повідомлення про помилку без перезавантаження сторінки.»
2. **Промпт для Tailwind:** «Перепиши сітку з 4 карток товарів на Tailwind CSS з адаптивністю: 1 колонка на мобільних, 2 на планшетах, 4 на десктопі.»
3. **Промпт для Fetch API:** «Напиши async/await функцію для відправки JSON-даних форми на тестове API `jsonplaceholder` з обробкою try/catch і блокуванням кнопки.»

## 3. Випадок помилки або потреби уточнення AI
* **Опис ситуації:** AI згенерував код з однаковими id у кнопках перемикання теми та некоректно використав `document.getElementById()`, що викликало конфлікт під час повторного кліку.
* **Як виправлено:** Додано чітку умову в промпт про унікальність ідентифікаторів та перевірку наявності елемента в DOM перед створенням події.

## 4. Власні правила ефективної роботи з AI
1. Завжди надавати AI контекст проєкту та конкретний файл, з яким працюємо.
2. Ніколи не копіювати код наосліп — перевіряти кожен рядок через Console в DevTools.
3. Розбивати великі завдання на маленькі підзадачі (окремо HTML-структура, окремо JS-подія, окремо стилі).
