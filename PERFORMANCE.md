## 2. Виконані кроки оптимізації
1. **Ліниве завантаження:** Додано атрибут `loading="lazy"` для зображень нижче першого екрана.
2. **Запобігання зсувам макета:** Для всіх картинки вказано явні атрибути `width` та `height`.
3. **Оптимізація JavaScript:** Перевірено підключення `script.js` з атрибутом `defer`.
4. **Шрифти:** Оптимізовано завантаження шрифтів за допомогою `font-display: swap`.
