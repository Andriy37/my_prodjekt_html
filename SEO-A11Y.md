## 2. Реалізовані покращення SEO
* Додано описові мета-теги `description`, `keywords`, `author` та `robots`.
* Налаштовано протокол **Open Graph** (`og:title`, `og:description`, `og:image`) для корректного шерингу в месенджерах.
* Забезпечено чітку ієрархію заголовків (`<h1>` для головного заголовка hero-секції, `<h2>` для розділів, `<h3>` для карток).

## 3. Реалізовані покращення Accessibility (a11y)
* Для всіх зображень прописано змістовні значення атрибута `alt`.
* Інтерактивні елементи мають відповідні ARIA-атрибути (`aria-pressed`, `aria-label`, `aria-hidden="true"` для декоративного SVG).
* Забезпечено високий контраст тексту та можливість повноцінної навігації клавіатурою (Tab / Focus).
* Збережено семантичну структуру DOM-дерева.
